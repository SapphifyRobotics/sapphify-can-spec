# ROTEM series CAN protocol

The normative protocol specification for every SAPPHIFY ROTEM CAN device.

**[Read the specification](ROTEM_SERIES_CAN_SPECIFICATION.md)** — draft v0.9.

Any team can write its own driver, replay its own logs, or integrate ROTEM into a non-WPILib
stack from this document alone. No SAPPHIFY software is required and no part of it is withheld.

The document is versioned with the firmware: a released firmware image always matches a released
specification version exactly. Where something is not yet decided it is listed as an open gap in
section 4 rather than left vague.
